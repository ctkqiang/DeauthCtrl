nmap-mac-prefixes.txt
======================

Source: Nmap project (https://nmap.org), file nmap-mac-prefixes,
generated by make-mac-prefixes.pl from the IEEE Registration Authority
OUI / MA-M / MA-S public registries (https://regauth.standards.ieee.org/).

License: Nmap Public Source License (NPSL), see https://nmap.org/npsl/
The data itself is a compilation of public IEEE registration records.

Copied unmodified from the Dolphy-App repository (GPLv3) for MAC vendor
identification in the NRF scanner and BLE peripheral tools. Vendor names
identify the registered network-interface vendor only, never the finished
device brand.
